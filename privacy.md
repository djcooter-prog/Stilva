# Stilva Privacy Policy

_Last updated: 13 November 2026 (feedback is now collected in the Fable Kingdoms server)_

This policy explains what information the Stilva Discord bot ("Stilva", "the bot") and its web dashboard collect, why, and what you can do about it. Stilva is a hobby project run by one person (the "operator"). It is not a company and does not sell or share your data for advertising.

## The short version

- Stilva stores **Discord IDs** (user, server, channel, role and message IDs) and the things you deliberately give it, such as feedback, ideas, event sign-ups and game moves.
- It **reads messages** in servers it's in so the word filter and spam protection work. It doesn't keep those messages unless they're posted in a feedback or ideas channel.
- Nothing is sold, and nothing is used for advertising.
- You can ask for your data to be deleted at any time (see [Your choices](#your-choices)).

## What Stilva collects

What Stilva stores depends on which features a server uses and what you do with the bot.

| Feature | What is stored | Why |
|---|---|---|
| All features | Your Discord user ID and the server ID, channel IDs and message IDs involved | To know who did what, in which server |
| Moderation | Warnings and moderation cases: the member's user ID, the moderator's user ID, the action (such as a timeout or ban), the reason and the time | So server moderators can keep a record of actions |
| Word filter and anti-spam | Message text is read as it arrives and checked, but **not saved** | To remove blocked words and stop spam |
| Events | The event details, its creator's user ID and display name, and the user IDs of people who said they're going | To show who's going and send reminders |
| Trivia | Your points per server | For the leaderboard |
| Feedback | The text you send, whether it's a bug or a suggestion, your user ID and username, which server you sent it from, and the time | So the operator can read and act on it. It's posted in the feedback forum of the Fable Kingdoms Discord server, showing your username and the name of the server you sent it from |
| Feature votes | Ideas you post (title and description), your user ID and display name, and which ideas you voted on | To run the vote and show the results. Feature votes happen in the Fable Kingdoms Discord server |
| Reaction roles, buttons, access groups and verification | Which reactions and buttons a server has set up. Your roles themselves are held by Discord, not by Stilva | To give and remove roles when you react or click |
| Creator alerts | The display name and profile link (for example a Twitch or YouTube channel) a creator submits, and whether it's approved | To post "now live" or "new video" alerts |
| Fable Kingdoms (game) | Your player record (user ID and server ID) and everything you do in the game: your settlement, buildings, troops, research, armies, battles, trades, messages from the game and scores | To run the game |
| Web dashboard | Your user ID and the server you logged in to, in a session cookie that lasts up to 7 days | To keep you logged in |

Stilva also gets basic information from Discord that every bot in a server can see, such as member lists, usernames, avatars and roles. Stilva only uses it while running features (for example, to show names in the dashboard or the game) and doesn't keep a separate copy beyond what the table above lists.

## Cookies

The web dashboard and the Fable Kingdoms game use one cookie to keep you logged in. There are no advertising or tracking cookies, and no analytics.

## Outside services

Stilva uses these services to work. Each has its own privacy policy.

- **Discord**: everything the bot does goes through Discord.
- **Cloudflare**: the web dashboard and the game are reached through a Cloudflare Tunnel, so Cloudflare handles that web traffic.
- **Twitch and YouTube (Google)**: used only when a server has creator alerts turned on, to check whether a submitted channel is live or has posted something new.
- **Lookup commands** (Open Trivia Database, CoinGecko, the Free Dictionary API, GitHub and wttr.in for weather): when you use one of these commands, only the thing you searched for (a word, a coin, a place or a repository) is sent. Nothing that identifies you is sent with it.

## Where it's stored and for how long

All data is stored in a database on the operator's own computer. It is not stored with any cloud provider. Backup copies of the database are kept on the same computer.

- Most data is kept while the bot is in the server, so features keep working (for example, moderation history and leaderboards).
- If Stilva is removed from a server, that server's data stays in the database but is no longer used. You can ask for it to be deleted.
- Fable Kingdoms data from finished seasons may be kept for season history and leaderboards.
- When data is deleted, copies may stay in older backups for a while until those backups are cleared.

## Who can see it

- **The operator**, to run and fix the bot.
- **Server staff** (people with Manage Server permission) can see their own server's data in the dashboard, such as moderation records, feedback and alert submissions.
- **Other members** can see what's meant to be public in that server, such as event sign-ups, leaderboards, idea votes and game rankings.
- **Members of the Fable Kingdoms Discord server** can see the feedback posted in its feedback forum (with the sender's username and server name) and its feature votes, wherever they were sent from.

Stilva does not sell, rent or trade your data, and doesn't share it with anyone else unless the law requires it.

## Your choices

- **Stop using a feature**: most data is only created when you use a feature.
- **Ask what's stored about you**: you can ask for a copy.
- **Ask for deletion**: you can ask for your data, or a whole server's data, to be deleted. Moderation records may be kept if a server's staff still need them for safety reasons. Server staff can also remove their own server's data by asking.

To make a request, email [stilvabot@gmail.com](mailto:stilvabot@gmail.com). Include your Discord user ID (and the server ID, for a server request) so your data can be found. Requests are usually answered within 30 days.

## Children

Discord requires users to be at least 13 (or older in some countries). Stilva is meant for people who meet Discord's age rules and doesn't knowingly collect data from anyone younger.

## Changes to this policy

If this policy changes, the new version will be posted on this page with a new "Last updated" date. Big changes will also be announced through the bot's patch notes where possible.
